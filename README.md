# aurinux.com

Sitio de Aurin para Estados Unidos: home y landings por estado, en español e inglés (`/en/`).
Astro 6 estático en Vercel, mismo stack, tokens y componentes que aurin.mx (`../AurinWebsite`).

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # dist/
```

Node 24 (`.nvmrc`). Estructura, reglas de marca, SEO, cómo agregar un estado y pendientes: [`CLAUDE.md`](CLAUDE.md).
El export original de Claude Design está en [`diseno-original/`](diseno-original/).

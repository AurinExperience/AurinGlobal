# Aurin · sitio estático

Para verlo: abre `index.html` en el navegador, o sirve la carpeta:

```
npx serve .
```

Para trabajarlo con Claude Code:

```
cd aurin-site
git init && git add . && git commit -m "Diseño inicial exportado del canvas"
claude
```

`CLAUDE.md` contiene las reglas de marca, SEO y pendientes, y Claude Code lo lee solo al iniciar.
